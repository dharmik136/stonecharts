# Changelog

All notable product and contract changes are recorded here. The project follows
Semantic Versioning for product releases, PEP 440 for Python package versions, and Go
module version conventions.

## [Unreleased]

### Added

- Phase 0 product and engineering governance system.
- Controlled document metadata, requirements, evidence, risk, and role registries.
- Product thesis, Alpha scope, renderer constitution, guarantee contracts, security
  controls, test strategy, benchmark protocol, and Alpha 1 release qualification plan.
- Architecture decisions for guarantee profiles, capability validation, signed
  stacking, adaptive runtime behavior, and typography/layout profiles.
- Documentation and traceability validation tool plus CI quality workflow.

### Known release blockers

- Active schema and validators overstate renderer capabilities and disagree on parts of
  the accepted input domain.
- Signed normal stacks and signed percent stacks do not yet implement the approved
  contract.
- Runtime browser and accessibility qualification is incomplete.
- Package versions, SBOM, provenance, and release evidence generation are not aligned
  with `0.0.1-alpha.1`.

## [0.1.0] - Unreleased historical metadata

The Python source currently reports this version, but no governed `0.1.0` product
release was qualified. It must not be treated as a published compatibility milestone.
