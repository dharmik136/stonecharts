# Skill: Compliance Review

## Objective

Check that project decisions, requirements, and release evidence are internally
consistent.

## Instructions

1. Read the product, project, and release documents that apply to the task.
2. Verify that status values, approvals, dependencies, and evidence references match.
3. Confirm that the requested work does not exceed the approved scope.
4. Flag any mismatch between the docs and the current repository state.

## Output

- Traceability summary
- Approval or mismatch list
- Required corrections
