# Skill: Plan

## Objective

Convert the request into a short execution plan with ordered work items, ownership
boundaries, and verification gates.

## Instructions

1. Break the work into the smallest reviewable steps.
2. Assign each step to one role where possible.
3. List the documents, code areas, and tests that must change.
4. Identify any dependency that must finish first.

## Output

- Ordered plan
- Blocking dependencies
- Files likely to change
- Checks that will prove completion
