# Skill: Security Review

## Objective

Assess the repository for realistic security risks and control gaps.

## Instructions

1. Review execution paths, dependency loading, secrets handling, and automation.
2. Check for overbroad permissions, unsafe defaults, and untrusted inputs.
3. Compare the implementation against the documented threat model and supply-chain
   policy.
4. Report concrete issues, not generic concerns.

## Output

- Findings ranked by severity
- Affected files or workflows
- Recommended mitigation
