# Skill: Intake

## Objective

Read the governing docs for the requested work and summarize the current scope,
blockers, and required checks before any edits are made.

## Instructions

1. Read `AGENTS.md`, `.agents/agents.md`, and the relevant project docs.
2. Identify the exact files, decisions, or requirements that govern the task.
3. Report any blocking approvals, scope limits, or verification gates.
4. Do not edit files.

## Output

- Current task scope
- Governing docs read
- Blocking decisions or approvals
- Required verification steps
