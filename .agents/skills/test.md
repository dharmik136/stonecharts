# Skill: Test

## Objective

Verify the current change set and report exact results.

## Instructions

1. Run the narrowest check that covers the change.
2. Expand to repo-level checks if the change affects shared contracts.
3. Capture failures with exact commands and file references.
4. Compare outputs only when the task depends on parity or determinism.

## Output

- Commands run
- Pass/fail status
- Exact failures if any
- Evidence relevant to the change
