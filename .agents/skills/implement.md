# Skill: Implement

## Objective

Make the approved repository change with minimal surface area and clear traceability.

## Instructions

1. Read the approved scope and the relevant source files.
2. Change only the files required for the task.
3. Keep output deterministic and consistent with the repo's established patterns.
4. Update adjacent docs, schema, or tests when the behavior changes.
5. Run the most relevant verification commands before handing off.

## Output

- Files changed
- Behavioral effect
- Verification performed
- Any follow-up work that remains
