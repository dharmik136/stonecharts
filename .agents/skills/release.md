# Skill: Release

## Objective

Prepare a release-ready handoff only after scope, tests, and evidence are complete.

## Instructions

1. Confirm the release target and version.
2. Check that required decisions and requirements are resolved.
3. Verify that the tree is clean and the evidence pack is current.
4. Assemble release metadata, changelog entries, and any final tags only when the
   release gate is satisfied.

## Output

- Release target
- Evidence status
- Missing gates, if any
- Final release actions
