# Performance Baseline Review

## Scope

This review records the approved 0.0.0.1 benchmark baseline for the Python and Go
renderers. It covers the controlled benchmark protocol defined in
[`docs/quality/benchmark-spec.md`](../../../quality/benchmark-spec.md), the
performance budget decision brief, and the persisted benchmark outputs generated by
the current local workspace.

## Commands run

- `python libs/python/benchmark.py`
- `go run ./cmd/benchmark`

## Evidence artifacts

- `libs/python/benchmark_results.json`
- `libs/go/benchmark_results.json`

Both files are machine-specific benchmark output (`.gitignore`d — raw timing and
memory figures are not portable across hardware) and are regenerated by the
commands above, not committed to the repository.

## Workloads covered

- Point counts: 3, 10, 100, 1000
- Layouts: Basic, Styled, Markers, Spline, Gradient
- Output modes: SVG and HTML

## Reviewed result

The benchmark run completed successfully for both language implementations and
persisted fresh result files for the approved workloads. The results establish a
repeatable baseline for render time, memory, and output size comparisons, but they do
not establish a release budget by themselves.

## Result

`BENCH-RENDER-BASELINE` is approved as the baseline evidence record for 0.0.0.1.
Release blocking thresholds remain a separate governed decision.
